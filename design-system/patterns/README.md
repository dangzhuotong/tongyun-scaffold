# 常用页面模式

- 工作台：侧栏 → 页面标题/日期 → 唯一主操作 → 进展卡 → 待办。任务状态带文字；不要把整个卡片和卡内按钮重复套交互区域。
- 列表/详情：筛选、结果数量、原生表格，行标题链接进入详情；窄屏允许表格局部横滚，不让整页横滚。详情提供返回入口、元信息和操作结果。
- 设置：标签始终可见、说明与输入关联；保存中禁止重复提交，失败保留输入并就地给恢复方式，成功后提供明确结果。页面卸载或新请求开始时取消/忽略旧响应。
- 空：说明当前范围无内容 + 一项下一步；加载：aria-busy 和可读文字；失败：保留当前数据和重试；无结果区分筛选为空与系统失败。
- 浮层：优先现有库；原生 dialog 必须 showModal()，提供标题、关闭按钮、Esc 和焦点返回。危险确认不承诺撤销；只有实现服务端取消才提供取消提交。

可运行例子在 examples/index.html。示例的设置、状态和详情无后端，生产接入者负责真实 API、取消语义、权限和持久化。测试异步页面时覆盖快速切换、重复点击、离开后返回及服务端失败。
