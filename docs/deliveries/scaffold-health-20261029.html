执行摘要

本仓没有 npm 依赖，安全/静态检查的等价工具是 shellcheck。修复前，CI 在 ubuntu 的 shellcheck 步骤因 SC2016 失败，macos 任务随之取消；修复后，两个平台全部步骤通过，并新增一条离线 README 初始化烟测，防止文档与脚本再次漂移。

04 / LIMITS

限制与风险

  • 本仓无 npm 依赖，npm audit 不适用；以 shellcheck 作为等价静态检查，并给出前后对比。
  • 开源 lite skill 仓仍是占位地址（仓名待定），README 的完整 skill 同步路径只能走降级警告；烟测使用 SKIP_SKILLS_SYNC=1 保持离线确定性。
  • 本机 Windows 无符号链接权限、无 Docker/WSL，未能本地复现 Linux 全量自检；以 CI 双平台结果为准。
  • PR 仅完成代码与验证，未合并、未发布；合并仍由人工审查决定。
